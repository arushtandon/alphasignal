# Saturday 31 Oct — one checklist

Copy the repo. Do not move it. Do this from an elevated PowerShell, with
Cursor closed so nothing writes the tree mid-copy. The paper bridge will be
stopped for the reboot at the end; that is the point.

1. Stop the bridge task. Leave Gateway logged in until the reboot.

```powershell
Stop-ScheduledTask -TaskName "AlphaSignal IBKR Bridge"
```

2. Copy.

```powershell
New-Item -ItemType Directory -Force -Path C:\src | Out-Null
robocopy "C:\Users\tando\Downloads\alphasignal-repo" "C:\src\alphasignal" /E /COPY:DAT /XJ /R:2 /W:2
```

`robocopy` exit codes 0 through 7 mean the copy worked. There is no `/MOVE`.
`data\`, `ibkr-bridge\logs\`, and `bridge-state.json` are inside the copy.

3. Verify the copy. All three have to pass before the next step.

```powershell
cd C:\src\alphasignal
git status --short
node --check server.js
node --check ibkr-bridge\bridge.js
```

`git status` in `C:\src\alphasignal` must match `git status` in
`C:\Users\tando\Downloads\alphasignal-repo` (same dirty files, same branch).
Then start the bridge from the new tree once, watch one log line, and stop it:

```powershell
$env:IBKR_DRY_RUN = "1"
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\src\alphasignal\ibkr-bridge\run-forever.ps1"
```

In another window:

```powershell
Get-Content "C:\src\alphasignal\ibkr-bridge\logs\bridge-$(Get-Date -Format yyyy-MM-dd).log" -Tail 20
```

Confirm a line `starting bridge commit=` from `C:\src\alphasignal`. Ctrl+C the
supervisor. Do not leave this dry-run supervisor running.

4. Point the scheduled task at the new script and apply the host settings.
   `-ApplyTask` asks for your Windows password (so the task can run when you
   are logged off) and replaces the interactive task.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\src\alphasignal\ibkr-bridge\host-hardening.ps1" -ApplyTask
```

5. Install IBC and point it at the **paper** login only, before the reboot.
   Full notes are in `docs/ib-gateway-autostart.md`. Do not put the password
   in the repo.

   - Download IBC from https://github.com/IbcAlpha/IBC/releases and unzip to `C:\IBC`.
   - Copy `config.ini.template` to `C:\IBC\config.ini`. Set `IbLoginId` and
     `IbPassword` for the paper user, `TradingMode=paper`,
     `OverrideTwsApiPort=4002`, `ReadOnlyApi=no`,
     `AcceptIncomingConnectionAction=accept`,
     `ExistingSessionDetectedAction=primary`.
   - In `StartGateway.bat` set `TWS_MAJOR_VRSN=1037` and `IBC_PATH=C:\IBC`.
   - If the paper user uses the IBKR Mobile key, IBC cannot tap the phone.
     Switch that user to a TOTP authenticator and put the secret in
     `config.ini`. IBKR still forces a full re-login about once a week
     (usually Sunday). On Monday, open Gateway, complete that login once,
     and leave AutoRestart on. The bridge sends `GATEWAY DOWN` after 10
     minutes if you forget, and `GATEWAY BACK` when port 4002 accepts.

6. Windows auto-logon with Sysinternals Autologon, not a hand-edited
   registry key. Download Autologon from
   https://learn.microsoft.com/en-us/sysinternals/downloads/autologon,
   run `Autologon64.exe`, enter the Windows account and password, and
   click Enable. It stores the secret as an LSA secret instead of a
   plain `DefaultPassword` value.

7. IBC starts when that account logs on:

```powershell
$action = New-ScheduledTaskAction -Execute "C:\IBC\StartGateway.bat" -WorkingDirectory "C:\IBC"
$trigger = New-ScheduledTaskTrigger -AtLogOn -User $env:USERNAME
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -ExecutionTimeLimit ([TimeSpan]::Zero)
Register-ScheduledTask -TaskName "IB Gateway Paper (IBC)" -Action $action -Trigger $trigger -Settings $settings -RunLevel Highest
```

8. Reboot once. Autologon opens the session, IBC logs the paper Gateway
   in, and the bridge task starts. Then lock the screen
   (Win+L). The session stays up; the desktop does not.

9. After the reboot, this is the sequence that means it worked:

   - Telegram `GATEWAY BACK` (a `GATEWAY DOWN` first is normal for the
     minute before IBC finishes logging in).
   - `ibkr-bridge\logs\bridge-<today>.log` contains
     `starting bridge commit=<hash> ibkr-bridge/=clean` and the path is
     `C:\src\alphasignal`.
   - https://alphasignal-dvg5.onrender.com/api/health has `bridge.offline`
     false and the dashboard has no "Bridge offline" banner.

```powershell
Get-Content "C:\src\alphasignal\ibkr-bridge\logs\bridge-$(Get-Date -Format yyyy-MM-dd).log" -Tail 30
```

10. Leave `C:\Users\tando\Downloads\alphasignal-repo` where it is for a week.
   Open Cursor on `C:\src\alphasignal` only. Delete the Downloads folder on
   **7 Nov**, after a week of the new tree being the one that runs:

```powershell
Remove-Item -LiteralPath "C:\Users\tando\Downloads\alphasignal-repo" -Recurse -Force
```
