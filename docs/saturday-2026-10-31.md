# Saturday 31 Oct — one checklist

Copy the repo. Do not move it. Do this from an elevated PowerShell, with
Cursor closed so nothing writes the tree mid-copy. The paper bridge will be
stopped for the reboot at the end; that is the point.

1. Stop the bridge task. Leave Gateway logged in until the reboot.

```powershell
Stop-ScheduledTask -TaskName "AlphaSignal IBKR Bridge"
```

2. Copy.

```powershell
New-Item -ItemType Directory -Force -Path C:\src | Out-Null
robocopy "C:\Users\tando\Downloads\alphasignal-repo" "C:\src\alphasignal" /E /COPY:DAT /XJ /R:2 /W:2
```

`robocopy` exit codes 0 through 7 mean the copy worked. There is no `/MOVE`.
`data\`, `ibkr-bridge\logs\`, and `bridge-state.json` are inside the copy.

3. Verify the copy. All three have to pass before the next step.

```powershell
cd C:\src\alphasignal
git status --short
node --check server.js
node --check ibkr-bridge\bridge.js
```

`git status` in `C:\src\alphasignal` must match `git status` in
`C:\Users\tando\Downloads\alphasignal-repo` (same dirty files, same branch).
Then start the bridge from the new tree once, watch one log line, and stop it:

```powershell
$env:IBKR_DRY_RUN = "1"
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\src\alphasignal\ibkr-bridge\run-forever.ps1"
```

In another window:

```powershell
Get-Content "C:\src\alphasignal\ibkr-bridge\logs\bridge-$(Get-Date -Format yyyy-MM-dd).log" -Tail 20
```

Confirm a line `starting bridge commit=` from `C:\src\alphasignal`. Ctrl+C the
supervisor. Do not leave this dry-run supervisor running.

4. Point the scheduled task at the new script and apply the host settings.
   `-ApplyTask` asks for your Windows password (so the task can run when you
   are logged off) and replaces the interactive task.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\src\alphasignal\ibkr-bridge\host-hardening.ps1" -ApplyTask
```

5. Reboot once.

6. After the reboot, before you rely on it:

```powershell
Get-Content "C:\src\alphasignal\ibkr-bridge\logs\bridge-$(Get-Date -Format yyyy-MM-dd).log" -Tail 30
```

You want a `[run-forever] starting bridge` line from the new path. Gateway
will not be logged in yet (see `docs/ib-gateway-autostart.md`), so a
`GATEWAY DOWN` Telegram after 10 minutes is expected until IBC or a manual
paper login is in place.

7. Leave `C:\Users\tando\Downloads\alphasignal-repo` where it is for a week.
   Open Cursor on `C:\src\alphasignal` only. Delete the Downloads folder on
   **7 Nov**, after a week of the new tree being the one that runs:

```powershell
Remove-Item -LiteralPath "C:\Users\tando\Downloads\alphasignal-repo" -Recurse -Force
```
